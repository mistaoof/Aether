# Using the Aether Codex in Roblox Studio via Claude

This guide connects a local Claude Code session to Roblox Studio, so Claude
can read/write scripts and instances directly in a Studio place while using
this repo's `codex/` files as source material for a game's magic system.

The connection is local-only: it runs entirely on the machine that has Roblox
Studio installed. A cloud or web session of Claude Code cannot reach Roblox
Studio, since Studio's MCP server only listens on that machine.

## Prerequisites

- Roblox Studio installed on Windows, with a place open.
- Claude Code installed locally (`npm install -g @anthropic-ai/claude-code` or
  the platform installer).
- A local clone of this repo, so Claude can read `codex/` files as context.

## 1. Enable the MCP server in Studio

1. Launch Roblox Studio and open the place you're working on.
2. Open the **Assistant** panel.
3. Click **⋯ ⟩ Manage MCP Servers**.
4. Toggle **Enable Studio as MCP server** on.

## 2. Point Claude Code at it

From a terminal on the same Windows machine:

```
claude mcp add --transport stdio Roblox_Studio -- "cmd.exe" "/c" "%LOCALAPPDATA%\Roblox\mcp.bat"
```

`mcp.bat` is generated by Studio itself and always resolves to the currently
installed Studio version's `StudioMCP.exe` — you don't need to edit it or
point at a specific version folder.

Equivalent JSON, if you're editing an MCP config file directly (e.g.
`.mcp.json` or Claude's settings) instead of using the CLI:

```json
{
  "mcpServers": {
    "Roblox_Studio": {
      "command": "cmd.exe",
      "args": ["/c", "%LOCALAPPDATA%\\Roblox\\mcp.bat"]
    }
  }
}
```

## 3. Verify the connection

1. Restart both Roblox Studio and Claude Code so the new server is picked up.
2. In Studio, go back to **Assistant ⟩ Manage MCP Servers**.
3. Confirm the client shows a green "connected" indicator.

## 4. What Claude can do once connected

With the server enabled, Claude (run locally) gets tools to:

- Read, edit, and search Luau scripts in the place.
- Inspect and search the instance hierarchy.
- Run Luau code in different execution contexts.
- Generate meshes, materials, and simple 3D models.
- Start/stop playtests and capture screenshots.
- Simulate keyboard/mouse input during a playtest.
- Look up Roblox API reference and best-practice docs.

## 5. Working from the Codex

Once connected, open your local clone of this repo alongside the Studio
project and point Claude at specific `codex/` files as the source of truth —
for example: "Using `codex/power-hierarchy.md` and `codex/spell-directory.md`,
scaffold a Luau `ModuleScript` that defines the Novice-tier spells listed in
the directory, with cost/backlash fields matching §3's tier costs."

Keep the direction of truth one-way: the Codex describes the fictional magic
system in prose and equations; a Roblox implementation is one interpretation
of it in game-code terms; the repo describes as-is text, not the reverse
translation. If a Studio session produces rules or numbers worth folding back
into the Codex itself, add them by hand following the conventions in the
repo's `CLAUDE.md` (global section/equation numbering, ASCII-only equations,
append-only edits with a changelog entry) rather than pasting Luau code into
`codex/`.
